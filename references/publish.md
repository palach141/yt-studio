# Описание, теги, главы

Поиск - рычаг меньше упаковки, но для вечнозелёных видео больше, чем кажется. Если видео
рассчитано на ленту подписчиков, скажи это и потрать силы на `references/package.md`.

## Описание

- **Первые две строки** - единственное, что читают: они видны до "ещё" и идут в сниппет поиска.
  Скажи, что даёт видео, словами, которые человек набрал бы в поиске.
- Затем ссылка или материал, если он есть.
- Затем главы.
- Затем длинная часть: что разобрано, для кого, что нужно знать заранее.

## Проверка запросами

Выпиши три поисковых запроса, по которым видео должно находиться, и проверь, что их слова есть в
заголовке и первых двух строках описания. Нет - проблема в заголовке, не в описании.

## Теги

Слабый сигнал. Используй для вариантов написания: названия инструментов, сокращения, транслит,
частые опечатки. До пятнадцати. Посторонние теги нарушают правила площадки.

## Главы

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/chapters.py transcript.srt
python3 ${CLAUDE_SKILL_DIR}/scripts/chapters.py transcript.srt --cuts cuts.json
python3 ${CLAUDE_SKILL_DIR}/scripts/chapters.py --check chapters.txt --duration 12:40
```

Число глав черновик выбирает сам по длине видео; `--target N` нужен, только если результат явно
мельчит или крупнит.

**Какая версия публикуется.** Если видео в этом разговоре резали через `cuts.py` или автор говорит,
что выкладывает вырезанную версию, главы делаются только с `--cuts` (файл - вывод
`cuts.py --json`): метки по исходному транскрипту на вырезанном видео опаздывают. Отдавай ОДИН
блок - для той версии, которая пойдёт на YouTube. Спрашивай, какая это версия, только если этого
правда нельзя понять из разговора.

1. Черновик даёт границы и первую фразу каждого раздела. Слова в скобках - не названия.
2. Прочитай транскрипт вокруг каждой границы. Черновик делит с запасом: границу, которая режет
   одну тему, удали. Глав столько, сколько в видео настоящих тем, но не меньше трёх. Границу,
   которая стоит рядом с началом темы, перенеси на фразу, где тема действительно начинается.
3. Назови каждую главу обещанием раздела, в 3-5 слов, голосом автора.
4. Сохрани итоговый блок с новыми названиями в файл и прогони `--check` с `--duration` той
   версии, которая публикуется (для вырезанной длину печатает черновик с `--cuts`). Отдавай только
   блок, который прошёл проверку: первая метка 0:00, минимум три метки, каждая глава от 10 секунд.
   Блок, нарушающий правило, YouTube молча не превращает в главы.

Раздел, который не получается назвать в пять слов, - это два раздела или вода. Скажи об этом.
