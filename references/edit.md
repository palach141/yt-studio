# Монтажный лист

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/cuts.py transcript.json
python3 ${CLAUDE_SKILL_DIR}/scripts/cuts.py transcript.json --edl cut.edl --clip raw.mp4
python3 ${CLAUDE_SKILL_DIR}/scripts/cuts.py transcript.json --edl cut.edl --fps 25
python3 ${CLAUDE_SKILL_DIR}/scripts/cuts.py transcript.json --ffmpeg raw.mp4
python3 ${CLAUDE_SKILL_DIR}/scripts/cuts.py transcript.json --json > cuts.json
```

Нет транскрипта - см. "Откуда брать входные данные" в SKILL.md: `fetch.py captions URL` для
уже загруженного видео или whisper для файла записи.

Если файл транскрипта сам битый (сломанные таймкоды, обрезанный json) и ты его чинишь - чини
копию, оригинал не трогай, и скажи об этом пользователю одной фразой.

## Сначала - какой транскрипт

Качество реза определяется таймкодами, и инструмент пишет уровень в первой строке:

- **слова** (whisper `--word_timestamps True --output_format json`) - видны паузы внутри фраз и
  отдельные "э-э". Это нужный вариант.
- **слова, концы оценены** (автосубтитры YouTube `.vtt`) - начала слов точные, концы прикинуты по
  длине слова. Годится как черновик; паузы короче секунды ненадёжны.
- **фразы** (`.srt`, обычный `.vtt`) - видны только паузы между фразами. Скажи об этом
  пользователю и предложи пересделать транскрипт, если запись длиннее 10 минут или если
  пользователь жалуется на паузы внутри фраз.

## Что находит

- **ПАУЗА** - тишина длиннее порога (`--floor`, по умолчанию 0.45 с); режется из середины, с
  каждой стороны остаётся половина порога, иначе речь звучит задыхающейся. Тишина до первого
  слова режется так же: перед словом остаётся половина порога.
- **ВОДА** - реплика из одних слов-паразитов, или отдельное "э-э" при таймкодах по словам.
  "Ну", "вот", "значит" внутри осмысленной фразы не трогаются: это может быть манера речи.
- **ДУБЛЬ** - фраза начата заново (совпали первые три слова и больше). Вырезается первая попытка
  целиком и пауза до второй; перед второй попыткой остаётся вдох в половину порога.

## Выход

- список находок и итог. Находки пересекаются и вкладываются друг в друга, поэтому в итоге два
  числа: "находок" и "мест на таймлинии" - столько резов реально будет в монтажке. Называй
  пользователю второе. Остаток короче 0.3 с между двумя резами отдельным куском не остаётся;
- `--edl` - CMX3600 из остающихся кусков для DaVinci Resolve / Premiere;
- `--ffmpeg` - готовая команда чернового реза с перекодированием;
- `--json` - то же для других инструментов: `regions` - области реза, `keep` - остающиеся куски.

Транскрипт кончается последним словом: всё, что в записи после него, в результат не попадает.

## Перед EDL - частота кадров и имя исходника

EDL считается в кадрах, поэтому до запуска с `--edl` узнай одно из двух:

- путь к исходному файлу - передай его в `--clip`, и fps прочитается из файла сам (нужен ffprobe,
  он ставится вместе с ffmpeg). Имя файла попадёт в EDL, по нему монтажка находит клип;
- или fps числом - передай в `--fps`. Если пользователь назвал и имя файла, и fps, а самого файла
  на диске нет, передай оба: `--clip имя.mp4 --fps 30` - имя нужно монтажке, чтобы найти клип. Новичку подскажи, где смотреть: в DaVinci Resolve - правый
  клик по клипу → Clip Attributes; либо свойства файла в системе (Windows: Свойства → Подробно,
  macOS: открыть в QuickTime → Окно → Показать инспектор фильма).

Инструмент пишет, откуда взят fps: "прочитан из файла", "задан" или "ПО УМОЛЧАНИЮ". В последнем
случае не отдавай EDL как готовый: на исходнике с другой частотой резы съедут. Спроси fps.

## Как загрузить EDL в монтажку

Обычно так; в твоей версии пункт меню может называться иначе:

- **DaVinci Resolve**: сначала добавь исходный клип в Media Pool, потом File → Import →
  Timeline… и выбери `.edl`.
- **Premiere Pro**: File → Import, выбери `.edl`; если клип не подцепился сам, привяжи его через
  Link Media.

Оговорки, которые надо сказать пользователю:

- EDL исходит из того, что таймкод исходника начинается с 00:00:00:00. У файлов с камеры он часто
  другой (время суток): тогда куски встанут не туда. Запись экрана и файлы с телефона обычно
  начинаются с нуля.
- Формат EDL проверен на корректность самого формата, а не на импорте в конкретную версию
  монтажки. Попроси пользователя сверить первые два-три реза глазами.

## Главы после реза

Таймкоды глав должны быть по таймлинии после реза, а не по исходнику. Сохрани рез в json и
передай его в главы:

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/cuts.py transcript.json --json > cuts.json
python3 ${CLAUDE_SKILL_DIR}/scripts/chapters.py transcript.json --cuts cuts.json
```

## Что сказать пользователю

Процент сокращения - это доля от длины всего транскрипта (от нуля до последнего таймкода), а не
только от речи. Если в записи есть молчаливая демонстрация экрана, инструмент сочтёт её паузой:
такие места надо вернуть вручную. Назови их, если видишь длинные паузы (больше 5 секунд) посреди
объяснения.
