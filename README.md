# yt-studio

Скилл для Claude, который помогает вести YouTube-канал на русском и английском: сценарий и хук,
заголовок с обложкой, монтажный лист, разбор удержания, поиск удачных видео в нише, Shorts, главы,
ответы на комментарии, план недели, аудит канала и журнал результатов.

Ничего не публикует и не входит в твой аккаунт. Он пишет и считает — выкладываешь ты.

*English: a Claude skill for running a YouTube channel — scripts and hooks, title + thumbnail
linting, cut lists from transcripts, retention analysis, niche outliers, Shorts, chapters. Works
with Russian and English content; the instructions and tool output are in Russian, Claude answers
in your language.*

## Установка

Нужен [Claude Code](https://claude.com/claude-code) и Python 3.8 или новее (на macOS и Linux он
обычно уже есть). Выбери один способ.

**Способ 1 — попросить Claude.** Вставь в Claude Code:

```
Установи скилл https://github.com/palach141/yt-studio и проверь, что он работает.
```

**Способ 2 — как плагин.** В Claude Code:

```
/plugin marketplace add palach141/yt-studio
/plugin install yt-studio@yt-studio
```

**Способ 3 — вручную, macOS / Linux:**

```bash
git clone https://github.com/palach141/yt-studio.git && sh yt-studio/install.sh
```

**Способ 3 — вручную, Windows (PowerShell):**

```powershell
git clone https://github.com/palach141/yt-studio.git; powershell -ExecutionPolicy Bypass -File yt-studio\install.ps1
```

**claude.ai (без Claude Code).** Собери архив командой `sh package.sh` и загрузи
`dist/yt-studio.zip` в Настройки → Возможности → Навыки. Инструменты там работают, но личные
файлы (описание твоего голоса, журнал) между разговорами не сохраняются.

После установки перезапусти Claude Code.

## С чего начать

Просто напиши, что тебе нужно, обычными словами. Команды знать не обязательно.

| Напиши | Получишь |
| --- | --- |
| «Что умеет yt-studio?» | проверку установки и список возможностей |
| «Придумай хук для видео про …» | пять хуков по разным формулам, два лучших с разбором |
| «Напиши сценарий на 8 минут про …» | сценарий по блокам с пометками, что на экране |
| «Как назвать видео про …?» | десять заголовков, три лучших и текст на обложку |
| «Вот субтитры, вырежи паузы» | список резов и файл для монтажной программы |
| «Сделай главы для описания» | блок таймкодов, проверенный по правилам YouTube |
| «Вот удержание, почему уходят?» | где именно уходят и одну правку, с которой начать |
| «Что заходит в моей нише? Вот каналы: …» (или список «название — просмотры») | видео, обогнавшие свой канал, и что у них общего |
| «Нарежь это видео на Shorts» | пять отрезков с таймкодами и новой первой фразой |
| «Ответь на комментарии» | сортировку и ответы, какой комментарий закрепить |
| «Спланируй неделю», «Разбери мой канал» | план под твои часы; одну главную правку |

Чтобы тексты звучали как ты, попроси: «собери описание моего стиля из этих видео» — и дай ссылки
или тексты двух-трёх своих роликов.

## Что ставить дополнительно (по желанию)

Без этих программ работает всё, кроме указанного. Claude сам предложит их, когда понадобятся.

| Программа | Что открывает | Установка |
| --- | --- | --- |
| yt-dlp | субтитры по ссылке и списки видео каналов | `brew install yt-dlp` / `winget install yt-dlp` |
| whisper | транскрипт с таймкодами по словам — точный рез пауз | `python3 -m pip install -U openai-whisper` |
| ffmpeg | черновой рез видео одной командой | `brew install ffmpeg` / `winget install ffmpeg` |

## Если что-то не работает

| Что видишь | Что делать |
| --- | --- |
| Claude не знает про скилл | перезапусти Claude Code; проверь, что есть папка `~/.claude/skills/yt-studio` |
| «python3: command not found» | поставь Python: `brew install python` или `winget install Python.Python.3.12` |
| «yt-dlp не установлен» | команда установки написана в самом сообщении |
| «нет субтитров на языке ru» | у видео нет русских субтитров — попроси другой язык или сделай транскрипт через whisper |
| резы «съехали» в монтажке | частота кадров не совпала с исходником — скажи Claude, какая она у твоего файла |
| что-то другое | напиши Claude «проверь yt-studio» — он запустит диагностику |

Диагностика вручную: `python3 ~/.claude/skills/yt-studio/scripts/doctor.py`

## Обновление и удаление

Обновить: `git pull` в папке репозитория и снова `sh install.sh`. Удалить: `sh install.sh --uninstall`.
Твои файлы — описание голоса и журнал — лежат отдельно в `~/.claude/yt-studio` и при обновлении и
удалении не трогаются.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `SKILL.md` | выбор режима и общие правила |
| `references/` | инструкция каждого режима, читается по требованию |
| `scripts/hook.py` | проверка первой фразы: штампы, вода, длина вслух, чужие слова, формула |
| `scripts/speech.py` | хронометраж сценария по блокам и проверка текста на чужие слова |
| `scripts/title.py` | проверка пары «заголовок + обложка» |
| `scripts/cuts.py` | паузы, слова-паразиты, дубли; экспорт EDL и команда ffmpeg |
| `scripts/chapters.py` | черновик глав и проверка готового блока |
| `scripts/retention.py` | удержание: хук, обрывы, всплески, склон |
| `scripts/outliers.py` | видео, обогнавшие медиану своего канала |
| `scripts/fetch.py` | субтитры и списки каналов через yt-dlp |
| `scripts/journal.py` | журнал: упаковка и результат каждого видео |
| `scripts/doctor.py` | диагностика и первичная настройка |
| `data/hooks.json` | 19 формул хука с шаблонами на русском и английском |
| `tests/` | проверки: `python3 tests/run_tests.py` |

Все инструменты — чистый Python без зависимостей, работают и отдельно от Claude; запуск без
аргументов печатает справку.

## Честно о границах

- Проверки хука и заголовка считают слова. Они ловят механические ошибки и не предсказывают
  просмотры; смысл оценивает Claude и ты.
- Рез точен настолько, насколько точны таймкоды транскрипта. Лучший вариант — whisper по словам.
- Файл EDL проверен на формат, но не на импорт в каждую версию монтажных программ: первый раз
  сверь на коротком куске.
- Пороги (60 и 40 знаков, три слова на обложке, 0,45 с паузы) — рабочие ориентиры. Правила самой
  площадки здесь только у глав: первая метка 0:00, минимум три метки, каждая глава от 10 секунд.
- Общих «норм» удержания и кликабельности скилл не называет: сравнивать стоит со своими же видео,
  для этого и нужен журнал.
